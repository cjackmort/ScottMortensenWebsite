# Scott Mortensen Fine Arts — site repo

This repo is the **live production site**, served via GitHub Pages
(source: `master` branch, root) at the custom domain **scottmortensenfinearts.com**.
Anything pushed to `master` here goes live immediately — there is no staging
step in this repo.

## Layout

- `index.html`, `about.html`, `gallery.html`, `process.html`, `contact.html`,
  `styles.css`, `script.js` — the current live site (5-page design with a
  cinematic hero, whole-image gallery tiles, constant-speed marquee).
- `old/` — the previous single-page homepage design, kept live at
  `scottmortensenfinearts.com/old/` so it isn't lost. Self-contained
  (`old/index.html`, `old/styles.css`, `old/script.js`, `old/coin.jpg`),
  reads shared photos via `../Photos/...`.
- `Photos/` — source images.
  - `Photos/*.JPG` / `*.JPEG` — full-resolution originals (10–17 MB each,
    36-megapixel camera files). Only `old/` and `tools/optimize-images.ps1`
    use these directly; do not reference them from new pages, they will
    tank load times.
  - `Photos/web/` — web-sized versions generated by
    `tools/optimize-images.ps1` (1600px + 800px variants, ~150–250 KB each).
    All current-design pages reference these. Regenerate after adding new
    photos to `Photos/`: `powershell -ExecutionPolicy Bypass -File tools/optimize-images.ps1`
- `server.js` — local static server for previewing (gitignored, not used by
  Pages). Run with `node server.js`, defaults to port 3000, honors `$PORT`.

## Workflow: don't experiment directly on this repo

Because this repo is live, **do exploratory/test changes in the sibling
repo `ScottMortensenWebsite-preview` instead** (same owner, GitHub Pages
enabled on its own `github.io` URL). Build and verify there, show it to the
client if needed, then port the approved changes over here as a deliberate
promotion (copy files across, fix any `Photos/` path differences, commit,
push). Don't treat `master` on this repo as a scratch space.

## Gotchas

- The marquee (`.marquee-track` in styles.css/index.html) loops via
  `translateX(-50%)`, which only works if the track is exactly two
  identical copies of the phrase list. Don't add a phrase to one half
  without the other — it snaps visibly on every wrap.
- Gallery tiles (`.g-img`) intentionally use `background-size: contain`
  with a blurred `::before` backdrop, not `cover` — this shows the whole
  sculpture rather than cropping it. Don't reintroduce a `scale()` zoom on
  `.g-img`, it re-crops the edges.
